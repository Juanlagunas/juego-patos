# ¿Los patos te ganan?

Juego en español con 50 escalones de retos de lógica, cálculo, observación y memoria, ambientado en una playa. Incluye pistas, intentos ilimitados y estrellas que se guardan en el navegador.

## Jugar en tu computadora

Abre `dist/index.html` en un navegador. No requiere instalación ni compilación.

## Pruebas

Con Node.js instalado, ejecuta desde la raíz del repositorio:

```sh
node --test tests/game.test.cjs
```

## Archivos

- `dist/`: juego completo y sus imágenes, listo para alojamiento estático.
- `tests/`: pruebas de generación de retos, respuestas, progreso y navegación.
- `docs/personaje-referencia.md`: documentación de las ilustraciones.
