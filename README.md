# Juegos de patos

Dos juegos en español que funcionan directamente en el navegador.

- **Patos en la playa:** abre `patos-playa/dist/index.html`.
- **Pasarela Patita:** abre `pasarela-patita/index.html`.

No requieren instalación. Cada carpeta contiene su documentación y pruebas.

## Pruebas

```sh
node --test patos-playa/tests/game.test.cjs pasarela-patita/tests/*.test.cjs
```
